## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

Dev server quirks (production builds aren't affected):

- Replaced an image under the same name and still see the old one? `/_image` results are cached by URL in
  `.wrangler/state/v3/cache`. Stop the server, delete that folder (only that one) and hard-refresh.
- Pages come back empty, or a new frontmatter field doesn't show up? Stop the server, delete `.astro/` and
  `node_modules/.vite`, start it again and wait about 15 seconds before the first request.

Blog covers and figures are generated by `/home/laptop/blogs/cover-art/isoart.py` (see its README).
